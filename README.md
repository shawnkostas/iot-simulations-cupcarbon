# iot-simulations-cupcarbon  

Introduction

This repository contains two simulation projects developed using the CupCarbon platform, focusing on smart city applications and Internet of Things (IoT) technologies.

The first project presents a simulation of urban bus routes within the city of Larissa, aiming to model public transportation movements and evaluate route behavior within a realistic urban environment.

The second project focuses on flood protection sensor activation scenarios, demonstrating how distributed sensor networks can be used for environmental monitoring and early warning systems. Through different simulation scenarios, the project explores the operation and response of sensors under potential flood-risk conditions.

Both projects are accompanied by presentation material and demonstration videos that illustrate their design, implementation, and simulation results. The purpose of this repository is to showcase the capabilities of CupCarbon in modeling smart transportation systems and environmental monitoring solutions within the context of smart cities.
